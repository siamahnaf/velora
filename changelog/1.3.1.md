### New

- **Check for updates.** Settings → General → About shows the installed version and has a button that checks for a newer one right away, and installs it if there is.

### Improvements and fixes

- **A properly sized icon.** The app icon is now the logo alone on a transparent background, so it fills its space in the Start menu, the taskbar and the title bar instead of appearing small inside a grey square.
- **The logo on the start screen.** The start screen shows the logo in place of the name.
