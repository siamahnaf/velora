# Velora

A video player for Windows, built on Tauri 2, Svelte 5 and libmpv.

Plays local files, links and magnet torrents in one window, with
frame-accurate seeking, seekbar previews, resume for every file, subtitle
search, chapters with a skip-intro button, a mini player and frame export.
Interface in English and Russian.

## Building

Requirements: Windows 10/11 x64, [Rust](https://rustup.rs) (stable, MSVC
toolchain, with the Visual Studio C++ Build Tools) and
[proto](https://moonrepo.dev/proto), which installs the Node.js and bun versions
pinned in [.prototools](.prototools) on first use. Binary SDKs are not
committed. The scripts below fetch them into `src-tauri/{lib,ffmpeg,tools}`,
and [.cargo/config.toml](.cargo/config.toml) wires in their paths.

```bash
bun install
bun run fetch-libs   # libmpv (LGPL) + FFmpeg SDK (LGPL, for the sidecar) + libclang (for bindgen)
bun run tauri dev    # development run
bun run tauri build  # NSIS installer → src-tauri/target/release/bundle/nsis/
```

### Tests

```bash
bun run gates        # svelte-check, the static checks and vitest
```

The sidecar decode paths have smoke tests. Generate a fixture with the bundled
ffmpeg first. The LGPL build has no GPL encoders, so use `mpeg4` rather than
libx264:

```bash
src-tauri/ffmpeg/bin/ffmpeg.exe -f lavfi -i testsrc2=duration=60:size=1280x720:rate=30 -c:v mpeg4 -q:v 5 test.mp4
cd src-tauri && VELORA_TEST_VIDEO=/path/to/test.mp4 cargo test --lib -- --nocapture
```

The Go services (`services/`) have their own test run, from the repository root:

```bash
go vet velora/... && go test -race velora/...
```

## Online services

Two features need a server, and Velora ships with no default for either. Each
is set in the settings, or as a default in the code:

- **Catalog metadata**: the TMDB proxy in `services/tmdb` (`DEFAULT_TMDB` in
  `src/lib/catalog.svelte.ts`).
- **Watching together**: the relay in `services/relay` (`DEFAULT_RELAY` in
  `src/lib/sync/wire.svelte.ts`).

Automatic updates are off (`UPDATES_ENABLED` in `src/lib/updater.svelte.ts`,
`plugins.updater` in `src-tauri/tauri.conf.json`).
