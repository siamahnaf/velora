### Improvements and fixes

- **A violet theme.** Buttons, switches, selections and progress bars now use Velora's violet.
- **A crisp icon.** The app icon is the logo exactly as drawn, with nothing around it, so it is sharp and full-size in the Start menu, the taskbar, the title bar and on the start screen.
- **The icon updates with the app.** After an update, Windows now picks up the new icon in the Start menu and taskbar instead of showing the old one.
