### Improvements and fixes

- **Pausing with the keyboard keeps the controls hidden.** Pressing Space (or K) to pause or resume no longer brings up the control bar, so the paused frame stays fully visible. Moving the mouse still shows the controls as before.
- **The Start menu shows the new icon after an update.** After an update, the Start menu now picks up a changed app icon as well, not only the taskbar.
