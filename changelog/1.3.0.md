### New

- **Subtitle size in the subtitle menu.** The subtitle menu over the control bar now has a size slider above the delay, so the size can be adjusted while watching. It is the same setting as in Settings, and the two stay in step.
- **Updates from GitHub.** Velora checks its GitHub releases for a newer version and offers to install it.

### Improvements and fixes

- **Smaller subtitles.** Subtitle size now goes down to 0.10×, where it used to stop at 0.50×.
- **A new look.** The accent colour now follows the logo's blue, and the app has its own name and icon.
